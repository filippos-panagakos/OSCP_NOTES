# Alternative Web Ports (8080, 8443, 8000, 8888, 9090, etc.)

Same approach as port 80/443 but these often run different services or admin panels.

## Common Services on These Ports

```
8080 - Tomcat, Jenkins, HTTP proxy, dev servers
8443 - HTTPS alternative, Tomcat SSL
8000 - Python dev server, Django
8888 - Jupyter Notebook, alternative HTTP
9090 - Cockpit (Linux web admin), Prometheus
9200 - Elasticsearch
9000 - SonarQube, portainer
3000 - Grafana, Node.js apps, Gitea
4848 - GlassFish admin
10000 - Webmin
```

## Webmin (10000)

```bash
# usually HTTPS
https://<target ip>:10000

# default creds: root:password or admin:admin
# check for CVEs, several RCE vulns exist
searchsploit webmin
```

Always run the same enumeration as port 80/443 (gobuster, nikto, whatweb, source code check) on alternative ports.
